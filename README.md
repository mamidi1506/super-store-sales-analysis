
🚀 Power BI Project – Super Store Sales Analysis Dashboard
Thrilled to share my recent project where I designed an interactive Power BI dashboard to analyze Super Store Sales across multiple metrics and regions.
 This project demonstrates how raw data can be turned into actionable insights using SQL, Power BI, and Excel.
📊 What I Built:
🔹 Page 1 – Sales Analysis
 • 📈 Tracked KPIs like Total Sales (1.57M), Profit (175K), Quantity Sold, and Ship Days
 • 📊 Used line charts for monthly sales and profit trends
 • 📂 Analyzed data by Category, Sub-Category, Segment, Payment Mode, and Shipping Modes
 • 🧭 Added slicers for Region and Product Category to enable dynamic filtering
🔹 Page 2 – Top Performance Overview
 • 🏆 Highlighted Top 5 Products, States, Cities, and Sub-Categories by Sales
 • 📦 Identified Top Returned Products to understand customer return behavior
 • 📋 Showcased most ordered items in a clean, business-focused layout
🔹 Page 3 – Custom Filter Page
 • 🎛️ Designed a custom filter pane using slicers for City, Product Name, and Sub-Category
 • 🧩 Enhanced user experience through drill-down exploration and interaction
🛠️ Tools Used:
 • 🧮 SQL – for data extraction, joins, aggregations
 • 📊 Excel – for data cleaning and preprocessing
 • 📈 Power BI – for dashboard creation, DAX calculations, and visual storytelling
📌 This project enhanced my ability to blend analytical thinking with dashboard design and UX principles.
